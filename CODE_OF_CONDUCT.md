# Code of Conduct

Mycena follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and make room for
people with different backgrounds, abilities and levels of experience. Harassment,
discrimination and personal attacks are not tolerated.

Report problems to the maintainer through a private GitHub security advisory
(<https://github.com/mycena-project/Mycena/security/advisories/new>) if you do
not want to discuss them in public. Reports are handled confidentially.
